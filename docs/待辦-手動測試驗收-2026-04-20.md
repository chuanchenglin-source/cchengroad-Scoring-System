## 可能出錯的地方（給 Claude 實例看的診斷指引）

| 症狀 | 可能原因 | 怎麼驗 |
|---|---|---|
| 頁面載入空白、console 出現 `sb.from is not a function` | Supabase JS SDK 沒載入 | 看 `supabase-client.html` 的 CDN `<script>` 是否運作 |
| `getBoxDefinitions` 回空陣列 | nested select 語法問題或 RLS 擋住 | 用 MCP `execute_sql` 直接查 `box_definitions` 應有 40 筆 |
| 送出後 alert 失敗錯誤 | RPC 參數名不對 / payload shape 問題 | 看 console 完整錯誤訊息 |
| 歷史頁空白 | `getPersonalHistory` 三層 JOIN 語法 | 在 Supabase SQL Editor 手動測 `SELECT ... from daily_reports with items with options` |
| Box 1「當下之舞」勾了沒送出去 | 半/全形括號正規化失效 | 在 console 印 `section.querySelector('input:checked').dataset.optionId` 看有沒有值 |
