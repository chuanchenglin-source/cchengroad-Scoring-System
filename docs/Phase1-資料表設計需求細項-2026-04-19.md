## 三、建議 Supabase 資料表設計

### 表 1：`teams`（大隊）

| 欄位 | 型態 | 說明 | 範例 |
|---|---|---|---|
| id | uuid | 主鍵（自動） | |
| code | text | 隊編代碼 | T01 |
| name | text | 大隊全名 | 第一大隊 |

> 預設 5 筆，固定不變。

### 表 2：`squads`（小隊）

| 欄位 | 型態 | 說明 | 範例 |
|---|---|---|---|
| id | uuid | 主鍵（自動） | |
| team_id | uuid | 所屬大隊（外鍵 → teams.id） | |
| name | text | 小隊名 | 航海之星 |
| leader_name | text | 小隊長姓名 | 小明 |

> **需要主工程師確認**：
> - 目前人員總表有「小隊名」欄位嗎？
> - 小隊總共有多少個？
> - 小隊長是固定的還是會變動？

### 表 3：`members`（隊員）

| 欄位 | 型態 | 說明 | 範例 |
|---|---|---|---|
