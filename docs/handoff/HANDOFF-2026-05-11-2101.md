## 6. 踩過的雷 / 注意事項

### clasp pull 會覆蓋本地檔案（踩 3 次）

- **永遠先 `git commit`** 再 `npx clasp pull`
- pull 後若工作樹被回退（情境 C）：`git checkout HEAD -- <file>` 從 commit 還原
- 沒 commit 的改動 = **永久丟失**（git 沒記錄無法救）

### clasp 副檔名 .js / .gs 衝突

- 一個 GAS script 不能同時有 `xxx.js` 和 `xxx.gs`（衝突）
- 設定 `.clasp.json` 加 `"fileExtension": "gs"` 統一
- pull 後若兩種都出現：合併內容到 .gs、刪 .js

### 副本（Scoring-Fork）特殊情況

- **副本 Script Property 沒設** → 會 fallback 到正式 Sheet（讀 OK 但寫入會污染）
- 新功能要先確認**沒有寫入操作**才能直接用副本（純讀取已驗證安全）
- 副本走 `main` 分支（不走 PR），跟另兩個 repo 不同

### CLAUDE.md 紅線（最常踩）

- 不動計分系統正式 GAS（Script ID `19ZCMtO64t7d...`）
- 不直接 push `main`（除了 Scoring-Fork 例外）
- push 前先 pull 對比 diff

### Skill 行為差異

- `/end-work` vs `/交棒`：前者收尾、後者交付（前者是後者的子集）
- skill 載入順序：Project-level > User-level > Plugin-level
- 同名 skill 在不同 repo 可能行為不同（不會衝突但會混淆）

### iOS Safari 兼容性提醒

- 不要用 `<input list="datalist">` 在手機（退化為鍵盤建議列）
- 不要在 `touchstart` listener 中 `preventDefault()` — 會卡死滑動
- 用 `click` 事件處理觸控選擇

### 時區陷阱

- 禁用 `new Date('YYYY-MM-DD T00:00:00')` + `toISOString().slice(0,10)`（台灣時區會跳 1 天）
- 改用 `new Date(dateStr + 'T12:00:00Z')` + `setUTCDate` + `getUTCDate`
