## 程式碼改動關鍵點解說（給你 review 時看）

### config.js
新增的常數 `SS_ID_MONITOR_DEDUCTION` 預設空字串，意思是「不啟用扣分顯示」。fallback 機制保證：副本沒設或正式環境忘記設，**history.html 行為等同改動前**，不會壞掉。

### webApp.js
- `getPersonalHistory(userId)` 現在收 userId 參數。原本 hardcoded `T01_小巴_大心` 是 dev 留下的測試值，spec 要求收參數，順手修了。
- `_readActiveDeductions(userId)` 是私有 helper（前綴底線約定），所有失敗情境（Sheet ID 空、Sheet/分頁不存在、欄位缺、型別錯）都 fallback 為 `{}` 不拋例外，確保 `getPersonalHistory` 不會因為扣分讀取出錯而整個壞掉。
- 排序：扣分按 `扣分時間` 升冪。

### history.html
- CSS 加在 `#grandTotal` 之後，用 `.deduction-row` / `.deduction-badge` / `.deduction-text` 三個 class
- `renderBoxes` 在每個日期列之後，若 `box{N}_deductions.length > 0`，逐筆插入紅色扣分行
- `calculateSummary` 新增 `totalDeduction` 與 `weekDeductions[w]` 累計，最後 grandTotal/weekScore 顯示時減掉
- `escapeHtml` 防止 reason / monitor_id 含 HTML 特殊字元時破壞 DOM
